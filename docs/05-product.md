# 05 — Product

> Phase 4 in [[00-project-brief]]. Builds on [[04-hypothesis]].

## To decide

- **Who is the first user?**
- **What problem does the MVP specifically solve?**
- **What does the agent do?**
- **What does the agent NOT do?** (just as important)
- **What does the user do themselves?**
- **What is the "minimum useful product"** — the smallest thing that
  actually proves something?

## Product philosophy (from the kickoff conversation)

Not a classic "lifestyle app" (sleep + fitness + diet + finances +
everything). The core can be much cleaner:

> You tell the agent what you want to accomplish. The agent helps you
> actually get it done.

The life domain is secondary — it can be used for studying, programming,
fitness, projects, work, hobbies, practical tasks.
