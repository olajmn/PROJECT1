# 01 — Research

What is known from outside the project. **Nothing here is researched
yet** — this is a starting list, not findings.

## What to look for

- What is a node?
- Does a node have an identity separate from its text?
- Can a structure be reused as a new instance?
- How does AI use the structure, if at all?

## Comparable tools

Tools where the node or the structure is the core:

| Tool | Kind |
|---|---|
| Tana | Nodes with types and fields |
| Workflowy, Logseq | Outliners: nested blocks |
| Obsidian, Heptabase | Notes and links; cards on a canvas |
| Mind-map tools | Visual trees |
